# Images Folder

Place your photos here named as:
- photo1.jpg
- photo2.jpg
- photo3.jpg
- etc.

You can then update the config object in js/script.js to use these local images instead of the placeholder URLs.

Example:
Change: { src: "https://picsum.photos/400/400?random=1", caption: "Our first selfie" }
To: { src: "images/photo1.jpg", caption: "Our first selfie" }
